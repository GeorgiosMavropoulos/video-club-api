# DVD ESCAPE CLIENT APPLICATION AND API WITH CRUD FUNCTIONALITY RUNNING ON NODE.JS EXPRESS SERVER

# Project description
 The DVD ESCAPE is a robust movie management system designed to allow users to manage a movie management web app. The web application enables user to to browse,search,update, delete, add a new movie, create a new category, delete an existing category and browse movies by category. This project demonstrates full impeccable CRUD (Create, Read, Update, Delete) operations through a restfull NODE.js/EXPRESS API system.

# Main API's ENDPOINTS
1. Access GET endpoint to get all movies example: http://localhost:4000/movies   

2. Access GET endpoint to get a specific movie providing its id example: http://localhost:4000/movies/:id 

3. access GET endpoint to det all categories example :http://localhost:4000/movies/categories 

4. Access GET endpoint to get all movies belonging to a specific category: http://localhost:4000/movies/categories/:category_name

5. Acceess GET endpoint to get a movie by providing its title example: http://localhost:4000/movies/title/:title

6. Access POST endpoint to create a new category example : http://localhost:4000/movies/categories 

7. Access POST endpoint to add a new movie example: http://localhost:4000/movies/create 

8. Access PUT endpoint to update movie's information by providing its id example: http://localhost:4000/movies/:id 

9. Access DELETE endpoint to delete a specific movie providing movie's id. Example: http://localhost:4000/movies/:id 

10. Access DELETE endpoint to delete a specific category providing category's name. Example: http://localhost:4000/movies/categories/del/:category_name

## Important notes to create a new movie
1. category_id defines movie's category not genre!
2. POST endpoint accepts file paths not binary format images
3. Store the desired movie image to the folder /uploads inside the API folder
4. Use this file path to add movie's image: /uploads/image_name.jpeg (replace image_name and jpeg with real's image name e.g /uploads/alien.png)

## Body structure to add a category through postman example (category_id is auto generanted)
{
    "category_name":"Action"
}

## Body structure to post or update a movie through postman example (id is auto generanted and the category id defines its category not the Genre)
{
    "category_id":3,
    "title": "Predator",
    "director": "John MacTiernan",
    "date":"1987",
    "plot:"A team of commandos on a mission in a Central American jungle find themselves hunted by an extraterrestrial warrior.",
    "genre":"Action",
    "image":"/uploads/predator.jpeg"
}

## Troubleshooting
# Problem: Server don't start
1. lsof -i :4000 (find which process uses port 4000)
2. kill -9 <PID>(replace PID with process)

# Cannot find any movies/categories or Empty grid on client
1. Check if Database is seeded
2. Re-run seed.js (npm run seed)

# Testcafe is failing
# Problem: Browser not found
1. Install chromium (sudo apt-get install chromium)
2. Re-run scripts

# POSTMAN or API endpoint tests are failing
# Common problem: Connection refused
1. Navigate to API folder
2. Re-run npm run start
3. Validate that server is listening: curl http://localhost:4000/movies

# Images not loading
# Common problem: 404 errors for images
1. Check if /uploads folder exists
2. Verify image paths in database using sqlite3 browser
3. Check file permissions: chmod 755 API/uploads/, chmod 644 API/uploads/*.jpeg
