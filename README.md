Project description

The DVD ESCAPE is a robust movie management system designed to allow users to manage a movie management web app. The web application enables user to to browse,search,update, delete, add a new movie, create a new category, delete an existing category and browse movies by category. This project demonstrates full impeccable CRUD (Create, Read, Update, Delete) operations through a restfull NODE.js/EXPRESS API system.

    Access POST endpoint to create a new category example : http://localhost:4000/movies/categories

    Access POST endpoint to add a new movie example: http://localhost:4000/movies/create

    Access PUT endpoint to update movie's information by providing its id example: http://localhost:4000/movies/:id

    Access DELETE endpoint to delete a specific movie providing movie's id. Example: http://localhost:4000/movies/:id

    Access DELETE endpoint to delete a specific category providing category's name. Example: http://localhost:4000/movies/categories/del/:category_name

Important notes to create a new movie

    category_id defines movie's category not genre!
    POST endpoint accepts file paths not binary format images
    Store the desired movie image to the folder /uploads inside the API folder
    Use this file path to add movie's image: /uploads/image_name.jpeg (replace image_name and jpeg with real's image name e.g /uploads/alien.png)

Body structure to add a category through postman example (category_id is auto generanted)

{ "category_name":"Action" }
Body structure to post or update a movie through postman example (id is auto generanted and the category id defines its category not the Genre)

{ "category_id":3, "title": "Predator", "director": "John MacTiernan", "date":"1987", "plot:"A team of commandos on a mission in a Central American jungle find themselves hunted by an extraterrestrial warrior.", "genre":"Action", "image":"/uploads/predator.jpeg" }

Troubleshooting
Problem: Server don't start

    lsof -i :4000 (find which process uses port 4000)
    kill -9 (replace PID with process)

Cannot find any movies/categories or Empty grid on client

    Check if Database is seeded
    Re-run seed.js (npm run seed)

Testcafe is failing
Problem: Browser not found

    Install chromium (sudo apt-get install chromium)
    Re-run scripts

POSTMAN or API endpoint tests are failing
Common problem: Connection refused

    Navigate to API folder
    Re-run npm run start
    Validate that server is listening: curl http://localhost:4000/movies

Images not loading
Common problem: 404 errors for images

    Check if /uploads folder exists
    Verify image paths in database using sqlite3 browser
    Check file permissions: chmod 755 API/uploads/, chmod 644 API/uploads/*.jpeg
